# Securing Identity in Microsoft Entra ID - A Pratical Guide for SMBs
Last updated: 01/10/2026

Part of the **Microsoft 365 Security Foundations** series — practical, production-tested guides for securing Microsoft 365 as a small or growing business.

A hands-on guide to building an identity security baseline in Microsoft Entra ID,written for small and medium businesses setting up Microsoft 365 for the first time or hardening an existing tenant.

This isn't theoretical — it's based on implementing these exact controls in a real, live Microsoft 365 production environment, not a lab. Where a decision involved a trade-off (licensing limits, team size, what's realistic for a small company), that's called out so you can make the right call for your own situation.

## What's covered

1. [Tenant Discovery and Baseline](./01-tenant-discovery-and-baseline.md)
2. [User, Group, and Role Structure](./02-user-group-and-role-structure/)
3. [Break-Glass Accounts](./03-break-glass-accounts/)
4. [Conditional Access Policies](./04-conditional-access-policies/)
5. [Privileged Identity Management](./05-privileged-identity-management/) *(planned — requires Entra ID P2)*

## Who this is for

Anyone responsible for Microsoft 365 security at a small or growing organization — IT lead, founder, a security enthusiast, or a current student learning cybersecurity — who wants a working baseline without an enterprise security team or budget.

Sections 1–4 are complete and verified in a live tenant. Section 5 is planned once Entra ID P2 licensing is in place.
